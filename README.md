# clock

An application for practising reading analogue clocks with a student.

The clock opens to the current time of your computer, all hands can be dragged with a mouse or touchscreen, and others will turn in accordance. If hands overlap, click near the tip of the hand to precisely select it.

There is a teacher control panel where:
- The time can be edited in digital format.
- An "arc" representing the time elapsed within the hour can be displayed.
- A toggle for an outer ring of minutes in intervals of 5 is present.
- You can toggle whether the seconds hand displays.
